# Demo runbook

1. Select the public-data acknowledgement and `Hints only` policy. Choose a learning support level; `Guided start` can load an editable plan that explains every prompt.
2. Save your current thinking, then use the visual lab to predict BFS's next frontier.
3. Submit the prediction before revealing the canonical state.
4. Diagnose the duplicate-frontier mutation through the Socratic scaffolds. If a lifecycle choice is rejected, use the recovery prompt and commit to the lifecycle event that preserves the frontier invariant.
5. Show the passing canonical test result and evidence map. Schedule the retry.

If hosting is unavailable, run the same fixture locally with `make setup`, start the API and web apps, and use the identical workflow.
