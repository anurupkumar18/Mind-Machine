# Demo runbook

1. Select the public-data acknowledgement and `Hints only` policy.
2. Commit a traversal plan and use the visual lab to predict BFS's next frontier.
3. Submit the prediction before revealing the canonical state.
4. Diagnose the duplicate-frontier mutation through the Socratic scaffolds, then commit to the lifecycle event that preserves the frontier invariant.
5. Show the passing canonical test result and evidence map. Schedule the retry.

If hosting is unavailable, run the same fixture locally with `make setup`, start the API and web apps, and use the identical workflow.
